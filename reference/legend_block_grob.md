# A block of legends in columns

A block of legends in columns

## Usage

``` r
legend_block_grob(columns, gap = 0.15)
```

## Arguments

- columns:

  A list of columns, each a list of ggplots whose legends are stacked
  top to bottom

- gap:

  Gap between legends and between columns, in inches

## Value

A grob (class \`bt_legend_block\`), its legends built when drawn
