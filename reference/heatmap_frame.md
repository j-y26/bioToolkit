# The x scale and theme shared by every row of a heatmap

The x scale and theme shared by every row of a heatmap

## Usage

``` r
heatmap_frame(cl, height, split.gap, bg)
```

## Arguments

- cl:

  Result of
  [`heatmap_column_layout()`](https://j-y26.github.io/bioToolkit/reference/heatmap_column_layout.md)

- height:

  Panel heights (inches)

- split.gap:

  Gap between blocks of columns (inches)

- bg:

  Background colour

## Value

A list of ggplot2 components
