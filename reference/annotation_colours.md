# Colours of an annotation strip

Colours of an annotation strip

## Usage

``` r
annotation_colours(annotation.cols, a, values, i)
```

## Arguments

- annotation.cols:

  List of colours named by annotation, or NULL

- a:

  Annotation name

- values:

  Its values (factor)

- i:

  Index of the annotation, choosing its default palette

## Value

Colours named by value
