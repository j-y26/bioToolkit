# Title of the x-axis of an MA plot

Title of the x-axis of an MA plot

## Usage

``` r
ma_x_title(method, mean.col, log_axis)
```

## Arguments

- method:

  Method the table was read with

- mean.col:

  Column of the mean given by the user, or NULL

- log_axis:

  Whether the axis is log10

## Value

A plotmath expression or a string
