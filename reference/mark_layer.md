# Dashed outlines around the cell clouds of each group

Dashed outlines around the cell clouds of each group

## Usage

``` r
mark_layer(paths, linetype, linewidth)
```

## Arguments

- paths:

  Output of
  [`mark_paths`](https://j-y26.github.io/bioToolkit/reference/mark_paths.md),
  with a colour column

- linetype, linewidth:

  Line type and width of the outlines

## Value

A polygon layer, drawn in vector form
