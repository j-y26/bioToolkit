# Resolve \`na.cutoff\` for one feature

Resolve \`na.cutoff\` for one feature

## Usage

``` r
resolve_na_cutoff(na.cutoff, v, geom)
```

## Arguments

- na.cutoff:

  "auto", NULL or a number

- v:

  Values of the feature over all plotted cells

- geom:

  The geom used

## Value

NULL or a number
