# Pick at most \`n\` cells per unit at random

Pick at most \`n\` cells per unit at random

## Usage

``` r
sample_per_unit(cells, n, seed)
```

## Arguments

- cells:

  A data frame with \`cell\` and \`unit\`

- n:

  Largest number of cells per unit (Inf for all)

- seed:

  Random seed

## Value

Cell names
