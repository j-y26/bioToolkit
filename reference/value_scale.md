# Continuous scale of the value axis

Continuous scale of the value axis

## Usage

``` r
value_scale(axis, log, percent, n.breaks, far = 0.05)
```

## Arguments

- axis:

  "x" or "y"

- log:

  Whether log10

- percent:

  Whether values are fractions labelled as percentages

- n.breaks:

  Desired number of breaks

- far:

  Expansion of the high end, as a fraction of the range (room for labels
  there)

## Value

A ggplot2 scale
