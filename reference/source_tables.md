# The source tables of a plot, one per ggplot of a patchwork

The source tables of a plot, one per ggplot of a patchwork

## Usage

``` r
source_tables(plot, prefix = NULL)
```

## Arguments

- plot:

  A ggplot or patchwork object

- prefix:

  Name of the plot, for nested patchworks

## Value

A named list of data frames
