# Enrichment results as a standardized table

Enrichment results as a standardized table

## Usage

``` r
as_enrichment(enrichment, ...)
```

## Arguments

- enrichment:

  Standardized results, or anything
  [`standardize_enrichment()`](https://j-y26.github.io/bioToolkit/reference/standardize_enrichment.md)
  reads

- ...:

  Arguments to
  [`standardize_enrichment()`](https://j-y26.github.io/bioToolkit/reference/standardize_enrichment.md)
