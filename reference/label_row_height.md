# Height of a row holding labels of several lines

Height of a row holding labels of several lines

## Usage

``` r
label_row_height(labels, cell.height, text.size)
```

## Arguments

- labels:

  Labels, lines separated by "\n"

- cell.height:

  Height asked for, in inches

- text.size:

  Font size in points

## Value

The larger of \`cell.height\` and the height of the longest label
