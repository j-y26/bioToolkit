# Colours of the three classes of a volcano plot

Colours of the three classes of a volcano plot

## Usage

``` r
volcano_colours(cols, ns = "grey75")
```

## Arguments

- cols:

  NULL, colours named \`up\`, \`down\` and / or \`ns\` (the others keep
  their default), or three unnamed colours in that order

- ns:

  Default colour of the non-significant genes, "grey75" unless the plot
  sets another

## Value

A vector of three colours named \`up\`, \`down\`, \`ns\`
