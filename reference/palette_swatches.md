# Swatches of one row of show_palettes()

Swatches of one row of show_palettes()

## Usage

``` r
palette_swatches(label, cols, ncol)
```

## Arguments

- label:

  Label of the row

- cols:

  Its colours

- ncol:

  Number of swatches per row

## Value

A data frame with one tile per colour: \`palette\`, \`x\`, \`y\`,
\`width\`, \`fill\` (hex) and \`label\` (index)
