# The rows of show_palettes(): a label and its colours each

The rows of show_palettes(): a label and its colours each

## Usage

``` r
palette_rows_input(palettes, type, single_label)
```

## Arguments

- palettes, type:

  As in
  [`show_palettes`](https://j-y26.github.io/bioToolkit/reference/show_palettes.md)

- single_label:

  Label of a single vector of colours

## Value

A list of colour vectors, named by the label of their row (made unique)
