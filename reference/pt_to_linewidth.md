# Convert a line width in points to ggplot2 \`linewidth\` units

ggplot2 draws a \`linewidth\` of 1 as \`ggplot2::.pt\` device line
widths, each of which is 1/96 inch, i.e. 0.75 pt.

## Usage

``` r
pt_to_linewidth(pt)
```

## Arguments

- pt:

  Line width in points

## Value

The \`linewidth\` giving that width
