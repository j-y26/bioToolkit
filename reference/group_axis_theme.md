# Theme of the group axis of a violin plot

Theme of the group axis of a violin plot

## Usage

``` r
group_axis_theme(flip, sz, bar.width = 3.5)
```

## Arguments

- flip:

  Whether groups are on the y-axis

- sz:

  Sizes from
  [`theme_sizes()`](https://j-y26.github.io/bioToolkit/reference/theme_sizes.md)

## Value

A theme
