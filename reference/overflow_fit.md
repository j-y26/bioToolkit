# Device size fitting a legend centred on a point of a centred gtable

Device size fitting a legend centred on a point of a centred gtable

## Usage

``` r
overflow_fit(legend, centre, total, margin)
```

## Arguments

- legend:

  Size of the legend

- centre:

  Position of the legend's centre within the gtable

- total:

  Size of the gtable

- margin:

  Smallest gap between the legend and the device edge

## Value

The device size
