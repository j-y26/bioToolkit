# Spread positions apart to a minimum distance, within limits

Spread positions apart to a minimum distance, within limits

## Usage

``` r
spread_positions(y, gap, lim)
```

## Arguments

- y:

  Positions

- gap:

  Smallest distance between neighbours

- lim:

  Range the positions are kept in, if they fit

## Value

The new positions, in the order of \`y\`
