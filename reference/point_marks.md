# One mark per cell for \`geom = "point"\`

One mark per cell for \`geom = "point"\`

## Usage

``` r
point_marks(cells, v, cut)
```

## Arguments

- cells:

  Cells of a panel, with x, y and highlight columns

- v:

  Values of the feature for these cells

- cut:

  The resolved \`na.cutoff\`

## Value

A data frame with cell, x, y, value and coloured columns
