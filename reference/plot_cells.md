# Cells of a Seurat object or rows of a data frame

Cells of a Seurat object or rows of a data frame

## Usage

``` r
plot_cells(object, cells)
```

## Arguments

- object:

  A Seurat object, or a data frame with one row per cell

- cells:

  NULL for all, or cell names / indices

## Value

Cell names (row names of a data frame)
