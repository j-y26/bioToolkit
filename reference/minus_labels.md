# Labels of a scale with a true minus sign

Labels of a scale with a true minus sign

## Usage

``` r
minus_labels(labels, transformation)
```

## Arguments

- labels:

  The \`labels\` of a continuous scale: a waiver, a function or a
  character vector

- transformation:

  The scale's transformation, which formats the breaks when \`labels\`
  is a waiver (as ggplot2 does)

## Value

A function of the breaks giving their labels
