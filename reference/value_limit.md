# Top of the value axis from \`y.max\`

Top of the value axis from \`y.max\`

## Usage

``` r
value_limit(y.max, f, v)
```

## Arguments

- y.max:

  NULL, a number or quantile ("q99"), or a vector named by feature

- f:

  Feature name

- v:

  Values of the feature that are drawn

## Value

A number, or NA for the full range
