# The arrows and labels of the dimension arrow grob

The arrows and labels of the dimension arrow grob

## Usage

``` r
dimension_arrow_children(dims, g, arrow_color)
```

## Arguments

- dims:

  The two labels

- g:

  The geometry, already scaled for the panel: a list with
  \`arrow_length\`, \`x_coord_adjust\`, \`y_coord_adjust\`,
  \`arrow_size\`, \`arrow_width\` and \`text_dst\` in cm,
  \`arrow_line_width\` (lwd) and \`text_font_size\` (points)

- arrow_color:

  Colour of the arrows and labels

## Value

A gList
