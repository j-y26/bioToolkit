# Resolve cells given as names or indices

Resolve cells given as names or indices

## Usage

``` r
resolve_cells(cells, all_cells, arg = "cells")
```

## Arguments

- cells:

  NULL, a character vector of cell names, or integer indices

- all_cells:

  All available cell names

- arg:

  Name of the argument, for messages

## Value

A character vector of cell names, a subset of \`all_cells\` in the order
of \`all_cells\`
