# Genes of a dot plot, with their groups

Genes of a dot plot, with their groups

## Usage

``` r
dot_feature_table(features)
```

## Arguments

- features:

  A character vector, or a named list of character vectors

## Value

A data frame with \`feature\`, \`id\` (unique per group and gene) and,
for a list, \`feature_group\` (a factor in list order)
