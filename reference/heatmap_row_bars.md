# Bars of the blocks of features of a heatmap, opposite the feature names

Bars of the blocks of features of a heatmap, opposite the feature names

## Usage

``` r
heatmap_row_bars(cl, rl, cols, label.side, width)
```

## Arguments

- cl:

  Result of
  [`heatmap_column_layout()`](https://j-y26.github.io/bioToolkit/reference/heatmap_column_layout.md)

- rl:

  Result of
  [`heatmap_row_layout()`](https://j-y26.github.io/bioToolkit/reference/heatmap_row_layout.md)

- cols:

  Bar colours named by block of features

- label.side:

  Side of the feature names

- width:

  Thickness of the bars in points

## Value

A ggplot2 layer
