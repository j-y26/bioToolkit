# Resolve the \`raster\` argument, accepting the deprecated \`rasterize\`

Resolve the \`raster\` argument, accepting the deprecated \`rasterize\`

## Usage

``` r
resolve_raster_arg(raster, dots)
```

## Arguments

- raster:

  NULL, TRUE or FALSE

- dots:

  The list of \`...\` arguments, which may hold \`rasterize\`

## Value

NULL, TRUE or FALSE
