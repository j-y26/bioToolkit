# Text sizes and line widths of \`theme_bioToolkit()\`

Text sizes and line widths of \`theme_bioToolkit()\`

## Usage

``` r
theme_sizes(base.size = NULL)
```

## Arguments

- base.size:

  If not NULL, the base text size; the small and large sizes are scaled
  with it so that their ratios are kept

## Value

A list with \`base\` (11), \`small\` (9), \`large\` (12), \`line\` (0.5;
thin lines) and \`axis\` (1; axis lines and ticks), in points
