# Colours of the labelled and other points of a rank plot

Colours of the labelled and other points of a rank plot

## Usage

``` r
rank_highlight_colours(cols)
```

## Arguments

- cols:

  NULL, two colours (labelled, other) or colours named \`labelled\` /
  \`other\`

## Value

Two colours named \`labelled\` and \`other\`
