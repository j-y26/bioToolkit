# Factor by which the dimension arrows are scaled for a panel

Factor by which the dimension arrows are scaled for a panel

## Usage

``` r
arrow_scale_factor(width, height, arrow_scale = 1)
```

## Arguments

- width, height:

  Size of the panel in inches

- arrow_scale:

  The \`arrow.scale\` given by the user

## Value

\`arrow_scale\` times the panel's shorter side over \`ARROW_REF_PANEL\`
(3.5 inches)
