# Axis labels for the dimensions of a reduction

Axis labels for the dimensions of a reduction

## Usage

``` r
reduction_dim_labels(reduction, dims = c(1, 2))
```

## Arguments

- reduction:

  Name of the reduction, e.g. "umap"

- dims:

  The two dimensions plotted, default is 1 and 2

## Value

A character vector of two labels, e.g. "UMAP-1" and "UMAP-2"
