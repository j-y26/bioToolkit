# Wrap long names after spaces, hyphens, underscores or commas

Wrap long names after spaces, hyphens, underscores or commas

## Usage

``` r
wrap_name(x, width)
```

## Arguments

- x:

  Names

- width:

  Maximum characters per line; NULL or Inf for no wrapping

## Value

\`x\`, with line breaks; a hyphen stays at the end of its line
