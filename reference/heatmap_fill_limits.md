# Colour limits of a heatmap

Colour limits of a heatmap

## Usage

``` r
heatmap_fill_limits(v, scale, signed, min.cutoff, max.cutoff)
```

## Arguments

- v:

  Values coloured

- scale:

  Whether they are z-scores

- signed:

  Whether the scale is centred on 0

- min.cutoff, max.cutoff:

  Cutoffs (number, "q##" or NA)

## Value

Two numbers
