# Layer of the dot-grid axes

Layer of the dot-grid axes

## Usage

``` r
grid_axis_layer(data, params)
```

## Arguments

- data:

  One row per tick (see \`GeomGridAxis\`)

- params:

  \`side\` ("left" or "bottom"), \`width\` and \`length\` of the line
  and ticks (pt), and \`top.trim\` (inches left out at the top of a left
  axis line)

## Value

A ggplot2 layer
