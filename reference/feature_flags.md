# Resolve a per-feature switch given as TRUE / FALSE or feature names

Resolve a per-feature switch given as TRUE / FALSE or feature names

## Usage

``` r
feature_flags(x, features, arg)
```

## Arguments

- x:

  TRUE, FALSE, or names of features

- features:

  All features

- arg:

  Name of the argument, for messages

## Value

A logical vector named by feature
