# Bars marking the split.by blocks of a violin plot

Bars marking the split.by blocks of a violin plot

## Usage

``` r
split_bar_layer(d, flip, side, cols, width, sz)
```

## Arguments

- d:

  Long table of one feature

- flip:

  Whether violins are horizontal

- side:

  Side of the bars

- cols:

  Bar colours named by block

- width:

  Thickness of the bars in points

- sz:

  Sizes from
  [`theme_sizes()`](https://j-y26.github.io/bioToolkit/reference/theme_sizes.md)

## Value

A ggplot2 layer
