# Size of a set of tick labels across the axis, measured when drawn

Size of a set of tick labels across the axis, measured when drawn

## Usage

``` r
label_extent(labels, size, angle = 0, across = c("height", "width"))
```

## Arguments

- labels:

  Labels (strings or plotmath expressions)

- size:

  Font size in points

- angle:

  Rotation of the labels in degrees

- across:

  "height" for labels of a horizontal axis (x), "width" for those of a
  vertical axis (y)

## Value

A grid unit
