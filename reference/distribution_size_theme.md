# Fixed panel sizes of a violin plot

Fixed panel sizes of a violin plot

## Usage

``` r
distribution_size_theme(
  d,
  flip,
  cell.width,
  cell.height,
  panel.width,
  panel.height
)
```

## Arguments

- d:

  Long table of one feature

- flip:

  Whether violins are horizontal

- cell.width, cell.height, panel.width, panel.height:

  As in
  [`VlnPlot_bioToolkit`](https://j-y26.github.io/bioToolkit/reference/VlnPlot_bioToolkit.md)

## Value

A theme
