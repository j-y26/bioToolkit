# Limits of each panel of a rank plot

Limits of each panel of a rank plot

## Usage

``` r
rank_panel_limits(df)
```

## Arguments

- df:

  Plotted table, with \`split\`, \`rank\` and \`value\`

## Value

A data frame with two rows per split (the lower-left and upper-right
corners): \`split\`, \`x\`, \`y\`
