# Values behind the panels of a feature plot

Values behind the panels of a feature plot

## Usage

``` r
feature_source_data(marks, hex)
```

## Arguments

- marks:

  Marks of all panels, with a panel column

- hex:

  Whether the marks are hexagon vertices

## Value

For cells, a data frame with cell, panel, x, y, value and coloured
columns; for hexagons, one row per tile with its centre
