# Sizes of labels in inches

Measured on a PDF device, plus 10 slightly wider font) and a small
padding on each side.

## Usage

``` r
rank_label_extent(labels, size, italic)
```

## Arguments

- labels:

  Labels (may contain line breaks)

- size:

  Font size in points

- italic:

  Whether the labels are italic

## Value

A list of \`w\` and \`h\`, in inches
