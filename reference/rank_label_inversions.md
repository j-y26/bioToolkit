# Number of pairs of labels stacked in the opposite order to their points

Number of pairs of labels stacked in the opposite order to their points

## Usage

``` r
rank_label_inversions(y, cy, group)
```

## Arguments

- y:

  Heights of the points

- cy:

  Heights of the labels' centres

- group:

  Group of each label (an end of the ranking); pairs are counted within
  groups

## Value

The number of pairs whose labels and points are in opposite vertical
order
