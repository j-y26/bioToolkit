# Deprecated: use ggplot_colors()

\`ggplotColours()\` was renamed
[`ggplot_colors`](https://j-y26.github.io/bioToolkit/reference/ggplot_colors.md)
in 1.0.0 (snake case, as the other colour helpers); it still works, with
a deprecation warning.

## Usage

``` r
ggplotColours(n = 6, h = c(0, 360) + 15, showColor = FALSE)
```

## Arguments

- n, h:

  As in
  [`ggplot_colors`](https://j-y26.github.io/bioToolkit/reference/ggplot_colors.md)

- showColor:

  \`show.colors\` of
  [`ggplot_colors`](https://j-y26.github.io/bioToolkit/reference/ggplot_colors.md)

## Value

As
[`ggplot_colors`](https://j-y26.github.io/bioToolkit/reference/ggplot_colors.md)
