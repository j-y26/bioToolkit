# Legends of a legend block, built and placed on the current device

Legends of a legend block, built and placed on the current device

## Usage

``` r
legend_block_layout(x)
```

## Arguments

- x:

  A legend block

## Value

A list of \`grobs\` (legends in viewports, top-left aligned), \`width\`
and \`height\` of the block, in inches
