# Colours of the classes of a quadrant plot

Colours of the classes of a quadrant plot

## Usage

``` r
quadrant_colours(cols, scheme = "consistency")
```

## Arguments

- cols:

  NULL, colours named by class (the others keep their default), or one
  unnamed colour per class of the scheme, in its order

- scheme:

  The \`color.by\` of the plot: "consistency" (up, down, inconsistent,
  other), "direction" (up, down, other) or "significance" (concordant,
  discordant, x_only, y_only, ns)

## Value

The colours of the classes of the scheme, named by class
